# Sample datasets

Canonical location for Hello Agent sample CSV files:

- `ecommerce_faqs.csv`
- `credit_card_terms.csv`
- `hospital_policy.csv`
- `saas_docs.csv`

**Note:** These files previously lived under `Datasets/`. On Windows the folder was renamed to lowercase `datasets/` (the paths `Datasets` and `datasets` cannot both exist on a case-insensitive filesystem). Use `datasets/` going forward.
